# Chat-3T

To run the program download both files into a python 3 IDE. Then run the chatServer.py file first
and then run the chatClient.py file. You can run them by typing python ‘filename.py’ in the IDE terminal.
The program works as a turn based chat system that also allows the users to play a rock paper scissors
game. The conversation first starts with the client. Whoever starts the game makes the first selection of
rock paper or scissors. Whichever the client or server that initiates the game also starts the next chat
when the game ends. The program does not accept blank string (‘’) as input for the chat and tells the
user to re-input a message. The program takes strings up to 4096 characters. The program prints
reponses except for ‘/q’ and the ‘/rockpaperscissors’ where it instead prints statements indicating the
client/server shutting down or playing a game
